# everetroindustry.github.io

Download page for **EVE Retroindustry** — a free, open-source EVE Online industry
tool for Windows, Linux and Android.

- **Website:** https://everetroindustry.github.io
- **Source code and releases:** https://github.com/EVERetroIndustry/Eve-retroindustry

The page reads the latest release straight from the GitHub API, so it needs no
edit when a version ships. Screenshots in `img/` are re-encoded copies of the
ones in the code repository.
